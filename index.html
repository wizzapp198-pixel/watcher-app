Watcher verbinden

Die Web-App steuert deinen Watcher über GitHub. Einmalig brauchst du einen Zugangsschlüssel (Token).

So erstellst du den Token

1
Unten auf „Token erstellen“ tippen und bei GitHub anmelden.
2
Name z. B. „Watcher Web“, Ablauf: 1 Jahr.
3
Repository access → Only select repositories → dein Watcher-Repo.
4
Permissions: Actions Read and write, Contents Read-only, Issues Read and write.
5
Generate token → kopieren → hier einfügen.
